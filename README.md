# Flashback releases

This is the official public mirror for Flashback Windows installers, release notes, and SHA-256 checksums.

- [Download and learn more](https://flashbk.gg)
- [Read the changelog](https://flashbk.gg/changelog)
- Report security issues privately to [support@flashbk.gg](mailto:support@flashbk.gg)

The application source is maintained separately. Do not download Flashback installers from unofficial mirrors.
